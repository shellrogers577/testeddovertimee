# React useState Counter

A beginner-friendly React counter using the `useState` hook.

## Run the project

1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open the terminal in that folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal.

The plus button increases the number. The minus button decreases it, but the number cannot go below zero.
